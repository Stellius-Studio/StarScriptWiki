## Description
True if the caster's main-hand item's equippable component is dispensable (can be equipped by a
dispenser).


## Attributes
None.


## Examples
```yaml
Skills:
- message{m="dispensable"} ?isequipdispensable @trigger
```


## Aliases
None.
