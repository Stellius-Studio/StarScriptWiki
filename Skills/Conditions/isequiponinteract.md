## Description
True if the caster's main-hand item's equippable component equips on interact (e.g. right-clicking
a mob with it equips it directly, like a saddle or a Wolf's armor).


## Attributes
None.


## Examples
```yaml
Skills:
- message{m="equips on interact"} ?isequiponinteract @trigger
```


## Aliases
None.
