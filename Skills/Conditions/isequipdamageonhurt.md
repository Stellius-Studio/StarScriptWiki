## Description
True if the caster's main-hand item's equippable component damages on hurt (loses durability
when its wearer takes damage).


## Attributes
None.


## Examples
```yaml
Skills:
- message{m="damages on hurt"} ?isequipdamageonhurt @trigger
```


## Aliases
None.
