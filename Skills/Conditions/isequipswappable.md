## Description
True if the caster's main-hand item's equippable component is swappable (can be swapped onto by
right-clicking while worn).


## Attributes
None.


## Examples
```yaml
Skills:
- message{m="swappable"} ?isequipswappable @trigger
```


## Aliases
None.
