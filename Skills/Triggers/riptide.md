## Description
Fires when a player uses a Riptide-enchanted trident (`PlayerRiptideEvent`).


## Config
None.


## Skill Variables
| Variable      | Description                  |
|-----------------|----------------------------------|
| `event-item`      | The material name of the trident used |


## Examples
```yaml
Skills:
- message{m="<aqua>Riptide!"} @trigger ~onRiptide
```
