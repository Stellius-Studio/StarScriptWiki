## Description
Fires when a player leaves a bed (`PlayerBedLeaveEvent`). The target location is the bed.


## Config
None.


## Skill Variables
None.


## Examples
```yaml
Skills:
- message{m="<aqua>Good morning!"} @trigger ~onBedLeave
```
