## Description
Fires when a player enters a bed (`PlayerBedEnterEvent`). The target location is the bed.


## Config
None.


## Skill Variables
None.


## Examples
```yaml
Skills:
- message{m="<aqua>Goodnight!"} @trigger ~onBedEnter
```
