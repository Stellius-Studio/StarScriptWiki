## Description
Kicks a player with an optional reason.


## Attributes
| Attribute | Aliases | Description                       | Default |
|-----------|---------|-------------------------------------|---------|
| reason    | r       | The kick reason shown to the player | none    |


## Examples
```yaml
KickAfk:
  Skills:
  - kick{reason="Kicked for being AFK"} @trigger
```


## Aliases
None.
