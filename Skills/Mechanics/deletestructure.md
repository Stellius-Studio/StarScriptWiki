## Description
Deletes a saved structure template's file and unregisters it.


## Attributes
| Attribute | Aliases | Description             | Default |
|-----------|---------|-------------------------------|---------|
| id        |         | The structure's namespaced key   | none (required) |


## Examples
```yaml
Skills:
- deletestructure{id=myplugin:arena1}
```


## Aliases
None.
