## Description
Adds the caster's/target's player as a member of a region.


## Attributes
| Attribute | Aliases | Description       | Default |
|-----------|---------|-------------------------|---------|
| id        |         | The region's id            | none (required) |


## Examples
```yaml
Skills:
- addregionmember{id=my_house} @trigger
```


## Aliases
None.
