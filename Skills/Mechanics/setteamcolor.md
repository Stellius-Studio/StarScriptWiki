## Description
Sets a scoreboard team's color, which also drives its members' nametag/glow color.


## Attributes
| Attribute | Aliases | Description                          | Default |
|-----------|---------|-------------------------------------------|---------|
| team      |         | The team's id                               | none (required) |
| color     |         | A `ChatColor` name (e.g. `RED`, `AQUA`)     | none (required) |


## Examples
```yaml
Skills:
- setteamcolor{team=red_team;color=RED}
```


## Aliases
None.
