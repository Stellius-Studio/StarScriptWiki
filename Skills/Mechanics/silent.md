## Description
Toggles whether an entity is silent (suppresses its ambient sounds).


## Attributes
| Attribute | Aliases | Description                                | Default |
|-----------|---------|-----------------------------------------------|---------|
| state     |         | `true` to silence the entity, `false` to restore its sounds | true    |


## Examples
```yaml
SilenceMob:
  Skills:
  - silent @self
```


## Aliases
None.
