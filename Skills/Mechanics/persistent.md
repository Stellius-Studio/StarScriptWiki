## Description
Toggles whether an entity persists (won't despawn naturally).


## Attributes
| Attribute | Aliases | Description                                | Default |
|-----------|---------|-----------------------------------------------|---------|
| state     |         | `true` to make the entity persistent, `false` to allow natural despawning | true    |


## Examples
```yaml
MakePersistent:
  Skills:
  - persistent @self
```


## Aliases
None.
