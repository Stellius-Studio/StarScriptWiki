## Description
Sets the server-list MOTD applied to all future pings.


## Attributes
| Attribute | Aliases | Description                          | Default |
|-----------|---------|-------------------------------------------|---------|
| text      |         | The MOTD text, in MiniMessage format        | none (required) |


## Examples
```yaml
Skills:
- setmotd{text="<gold>Welcome to <bold>My Server<reset><gold>!"}
```


## Aliases
None.
